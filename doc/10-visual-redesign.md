## 4. 动效系统

### 页面入场

- 页面整体：800ms，上移 14px + 淡入。
- 文案：900ms，上移 24px并消除 6px 模糊。
- 产品场景：1100ms，从右侧 55px 和 0.92 缩放进入。

缓动统一使用 `cubic-bezier(.22,1,.36,1)`，获得前快后慢的高级感。

### 常驻环境运动

- 前后设备壳：6 秒上下漂浮，角度只变化 3–4 度。
- 外轨道：18 秒一圈。
- 内轨道：14 秒反向一圈。
- 悬浮卡：5.2–5.6 秒、10px 幅度错峰运动。
- 投影：5 秒轻微缩放和透明度变化。

这些运动的幅度刻意较小，避免工具类页面显得像宣传动画。

### Agent 状态动效

- `is-running`：轨道加速，状态点脉冲。
- `is-complete`：前后设备壳从分散位置聚合。
- 新海报方案：900ms 上浮、缩放并消除模糊。
- 事件轨迹：每项相隔 80ms 从右侧进入。
- 追问：500ms 小幅缩放进入，不使用警告式抖动。

### 可访问性

`prefers-reduced-motion: reduce` 下：

- 所有动画压缩到 0.01ms。
- 取消循环动画。
- 取消平滑滚动和长过渡。

## 7. 首屏标题排版修订

### 发现的问题

原标题只有一个强制换行，字号又按整个视口宽度放大。在约 `1190px` 的窗口中，左侧文字列已经变窄，但“生长出完整视觉”仍保持过大的字号，因此被浏览器拆成不受控的三行；配合 `0.88` 的紧行高，形成文字相互挤压和孤字掉行。

### 调整方式

- 将标题拆成语义明确的两组：第一行“从一句需求”，第二组“生长出 / 完整视觉”。
- 桌面端锁定为两行，缩小视口字号增速并把行高提高到 `0.96`。
- 第二行轻微缩进，通过字重和白色强调建立视觉层次，不再依赖文字重叠制造冲击力。
- 标题与说明文案之间的间距由 `30px` 增加到 `38px`。
- 手机端主动变成三行，并让“完整视觉”继续缩进，保证每一行都是设计决定而不是自动换行结果。

### 验收视口

- PASS `1190×708`：复现用户截图宽度，无孤字、无重叠，标题稳定为两行。
- PASS `1024×768`：双栏状态下标题完整，未侵入右侧动效主体。
- PASS `768×900`：进入单列布局，标题与动效场景留白清晰。
- PASS `390×844`：标题主动切成三行，正文留白和行动按钮位置正常。
- PASS Chrome 控制台 warning/error 为 0。

# 00 · 项目范围

## 1. 项目目标

PosterPilot 是一个电商活动海报设计 Agent。它帮助用户将模糊的营销需求转成结构化设计方案，并逐步支持生成素材、编辑图层、对话修改、版本恢复和导出。

求职价值不在于“套一个模型 API”，而是证明以下能力：

- 把开放式需求收敛成有限任务。
- 用状态机管理 Agent 的暂停、恢复、失败和完成。
- 用结构化协议连接模型、工具和前端画布。
- 处理生成式任务的异步进度、错误恢复和版本记录。
- 在成本、延迟、确定性和体验之间做工程取舍。

## 2. 核心用户

- 小型电商商家或运营人员。
- 没有专业设计能力，但能说明产品、活动和卖点。
- 需要快速获得一张可继续编辑的活动海报，而不是一次性不可修改图片。

## 3. V1 必须闭环

```text
输入产品/活动/卖点
        ↓
Agent 判断信息是否充分
   ↙             ↘
结构化追问       生成 DesignPlan
   ↓                  ↓
用户补充          生成/选择视觉素材
        ↘             ↓
          渲染可编辑图层
                 ↓
           对话修改某一图层
                 ↓
            保存版本并导出 PNG
```

## 4. 当前 Phase 1 范围

已做：

- brief 表单。
- 关键信息完整性判断。
- 结构化追问。
- `commerce-poster` Skill 路由。
- 本地确定性 Planner。
- `DesignPlan` 图层协议。
- Web 端视觉预览。
- Agent 事件轨迹。
- 单元测试、类型检查和构建脚本。

尚未做：

- 真实 LLM Provider。
- 图片生成或抠图工具。
- Fabric.js 可编辑画布。
- SSE 实时事件。
- PostgreSQL/Redis/对象存储。
- 登录、分享、云端部署。

## 5. 明确不做

- 通用型“什么都能做”的设计 Agent。
- 复制任何在职/前公司私有代码、提示词或接口。
- 自研基础图片生成模型。
- 首版支持视频、3D、PPT、Logo 等多个设计品类。
- 在没有监控和限额前开放无限生成。

## 6. 成功指标

技术验收：

- 完整 brief 能得到合法 `DesignPlan`。
- 不完整 brief 不误执行，返回对应字段的追问。
- 前端能显示 Agent 每个关键事件。
- 每个阶段有可复现命令和验收记录。

作品验收：

- 5 分钟内可以演示完整主流程。
- README 能让其他开发者在 10 分钟内启动项目。
- 面试时能解释一次关键取舍和一次失败恢复设计。
- Git 历史能体现逐阶段实现，而非一次性代码倾倒。
